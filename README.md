# 브레이크다운 Xbox 한글패치

Xbox 일본판 **브레이크다운(ブレイクダウン, Breakdown)**용 비공식 한국어 패치입니다. 다음 항목을 한국어로 바꿨습니다.

- **대사·자막:** 게임 중 대사 자막, 무전, 튜토리얼 안내, 아이템·파일 설명 등 번역 단위 1,493개 전체 (`*.pak`의 CAP 문자열)
- **메뉴·시스템:** 메인 메뉴·옵션·엑스트라 설명, 일시정지 메뉴, 소지품·스킬, 세이브·로드·저장 공간 안내, 지도·세이브 화면 지역 이름
- **글꼴:** 시스템 글꼴과 자막 글꼴에 한글 글리프 추가 (나눔스퀘어네오)
- **동영상:** 시작 경고 화면, 오프닝(스테레오·5.1ch판)과 엔딩 동영상의 일본어 자막
- **그림 글자:** 컨트롤러 설정 라벨, 종료 확인 문구, 타이틀 로고 아래 한글 표기 「브레이크다운」
- **배경 텍스처:** 표지판·안내판·경고문·전시 패널·신문 등 일본어가 적힌 배경 텍스처 64장 (아주 작은 글씨는 갈무리)

현재 배포판은 **v1.0 (2026-11-21)**입니다.

## 게임 소개 및 대상 버전

『브레이크다운』은 남코가 2004년 Xbox로 내놓은 1인칭 액션 게임입니다(일본 2004년 1월 29일, 북미 2004년 3월). 기억을 잃은 채 연구소의 병실에서 깨어난 주인공 데릭 콜이 정체불명의 여성 알렉스와 함께 연구소를 탈출하며 자신의 과거와 초인적 존재 「틀란」의 비밀을 쫓습니다. 시점이 끝까지 주인공의 눈에 고정되어 있어, 사격뿐 아니라 맨손 격투·사다리 오르기·음식 먹기까지 1인칭으로 표현한 것이 특징입니다.

일본판 디스크에는 일본어·영어 문자열이 함께 들어 있습니다. 이 패치는 두 문자열이 모두 한국어를 가리키게 바꿨으므로 어느 쪽이 쓰이든 한국어로 나옵니다.

이 패치는 **일본판 XISO**에만 적용됩니다. 파일 이름보다 아래 표의 크기와 해시가 맞는지가 중요합니다.

## 패치 적용 방법

### 1. 해시 확인

```powershell
Get-FileHash -Algorithm MD5 -LiteralPath '.\Breakdown (Japan).iso'
```

위 표와 다르면 적용을 중단하세요.

### 2. xdelta UI로 적용

1. 릴리즈에서 `Breakdown_Xbox_KO_v1.0.xdelta`를 받습니다.
2. xdelta3 패치를 지원하는 도구에서 **Apply Patch** 기능을 엽니다.
3. **Patch**에는 xdelta 파일을, **Source File**에는 해시가 일치하는 원본 `.iso`를 선택합니다.
4. **Output File**에는 새 파일 이름을 지정합니다(예: `Breakdown (Korean).iso`).

xdelta는 호환성을 위해 압축·2차 압축·파일 경로 헤더 없이 만들었습니다. xdelta 자체는 [공식 프로젝트](https://github.com/jmacd/xdelta)를 참고하세요.

### 명령줄로 적용

```powershell
.\xdelta3.exe -d -s '.\Breakdown (Japan).iso' '.\Breakdown_Xbox_KO_v1.0.xdelta' '.\Breakdown (Korean).iso'
```

결과 ISO는 xemu에서 그대로 실행할 수 있습니다. 파일 구조와 크기는 원본과 같으므로 실기에서도 원본 XISO와 같은 방법으로 쓸 수 있습니다.

**세이브**
- 타이틀 ID는 원본과 같으므로 원본판 세이브 데이터를 그대로 쓸 수 있습니다.
- 에뮬레이터의 세이브 스테이트는 원본판에서 만든 것을 쓰지 마세요.

## 한글화 범위

- **문자열(`*.pak`의 CAP):** 시스템 메시지와 지역별 자막 23묶음의 문자열을 번역 단위 1,493개로 나눠 전부 번역했습니다. 일본어 항목과 영어 항목이 같은 한국어 데이터를 가리키게 했습니다. 지도·세이브 화면의 지역 이름(건물·층·방 이름 조합)은 규칙 표(`text/loc.py`)로 옮겼습니다.
- **글꼴:** 원본 글꼴 텍스처 빈 칸과 새 텍스처에 쓰이는 한글만 골라 넣었습니다. 시스템 글꼴은 나눔스퀘어네오 Rg 18px, 자막 글꼴은 나눔스퀘어네오 Bd 28px입니다.
- **동영상(`romdata/movie`):** 시작 경고 화면(`warning.xmv`)의 일본어 경고문을 한글로 바꿨습니다. 일본어 자막이 구워진 오프닝 2종과 엔딩을, 같은 장면의 자막 없는 영상 위에 한글 자막을 그려 WMV2로 다시 인코딩했습니다. 음성·길이·파일 크기는 원본과 같습니다.
- **그림 글자:** 컨트롤러 설정 화면 라벨 18개, 일시정지 메뉴의 종료 확인 문구, 타이틀 로고 아래 「브레이크다운」
- **배경 텍스처:** 「출입 금지」·「비상구」·「흡연 구역」·「견학 경로」 같은 표지판, 경고문, 전시실 패널 제목, 신문 표제 등 64장. 텍스처가 같은 그림을 여러 맵에서 쓰는 경우 71개 파일에 모두 반영했습니다.
- **원문 유지:** 음성(영어), 메뉴 항목 이름 등 원래 영어로 된 그림 글자(MAIN MENU·NEW GAME·EASY 등), 스태프 크레디트, 상품 로고, 너무 작아 읽을 수 없는 서류·바인더 글씨

## 알려진 한계

**표기**
- 그림 글자와 배경 텍스처는 원래 칸 크기에 맞추느라 일부 글자 폭을 줄였습니다.

**확인 범위**
- xemu에서 직접 플레이하며 확인한 화면은 다음과 같습니다.
  - 시작 경고 화면, 오프닝 동영상, 타이틀, 메인 메뉴·옵션·엑스트라(음악 감상·갤러리) 전체
  - 새 게임 시작 후 수술실·병실 장면과 대화, 일시정지 메뉴, 소지품·스킬 화면
  - 병실 밖 복도와 「출입 금지」 표지판
- 재활실 튜토리얼 이후 구간은 게임 화면으로 확인하지 못했습니다. 이후 구간의 자막과 배경 텍스처는 데이터와 그림 파일로만 확인했습니다.
- 실기 Xbox에서의 동작은 확인하지 못했습니다.
