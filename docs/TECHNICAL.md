# 기술 설명

## 디스크

- XISO(Xbox 게임 파티션) 형식입니다. `tools/xiso.py`가 디렉터리 트리를 읽어 파일 목록(섹터·크기·경로)을 만들고, `tools/isopatch.py`가 각 파일 자리에 그대로 덮어씁니다. 모든 결과 파일이 원래 크기 이하라 파일 배치를 바꾸지 않습니다.

## 문자열 (CAP)

- `romdata/common/base.pak`(시스템 메시지)와 각 지역 `*.pak`(자막·안내)에 `CAP` 데이터가 일본어용(`cap_xxx`)·영어용(`cap_xxx_e`) 두 벌씩 들어 있습니다.
- CAP은 글꼴 표(글꼴 텍스처 번호·칸 크기), 글리프 표(텍스처 안 좌표·폭), 문자열 표, 16비트 코드 열로 되어 있습니다. 코드 1은 줄바꿈, 3은 공백, 6은 표시 시간(부동소수점), 0xC는 가변 길이 인라인 값(버튼 아이콘·숫자)이고, 0x100 이상이 글리프 번호입니다.
- 영어 CAP을 기준으로 문자열을 제어 코드 사이의 텍스트 조각으로 나누고, 같은 조각 조합을 하나의 번역 단위로 묶었습니다(1,493개). 한국어는 조각 수를 원문과 맞추고(` ¦ `로 구분) 제어 코드는 원래 자리에 둡니다.
- 새 CAP 하나를 만들어 일본어 항목 자리에 쓰고, 일본어·영어 두 항목의 오프셋과 크기가 모두 그것을 가리키게 했습니다. 영어 항목이 쓰던 공간까지 합쳐 쓰므로 길어진 한국어도 들어갑니다.

## 글꼴

- 시스템 글꼴은 `base.pak`의 18px 텍스처 3장, 자막 글꼴은 28px 텍스처 4장을 씁니다.
- 원본에서 계속 쓰는 영문·숫자·기호 글리프는 남기고, 나머지 칸과 빈 공간에 그 묶음에서 쓰이는 한글만 그려 넣습니다(나눔스퀘어네오, 4배 크기로 그린 뒤 축소, 테두리 포함).

## 그림

- `r_BD00.ast`·`r_PauseMain.ast`는 TIM2 계열 텍스처 묶음입니다. 컨트롤러 설정 라벨과 종료 확인 문구 텍스처의 글자를 지우고 한글을 그렸습니다(`tools/img.py`).
- 타이틀 로고 텍스처 아래 여백에 주황색 외곽 광채를 넣은 「브레이크다운」을 그렸습니다(`tools/logo.py`).

## 배경 텍스처

- 각 맵의 `*.nut`은 텍스처 묶음입니다. 텍스처 머리말 `+0x13`의 형식 값이 0x08이면 DXT1, 0x0C면 DXT5, 0x05면 256색 팔레트(모턴 순서 스위즐)이고 `+0x11`이 밉맵 수입니다(`tools/nutall.py`, `tools/tex.py`).
- 맵 전체 텍스처를 그림 내용 해시로 묶어 번호를 매기고(`tools/mkmap.py`, 3,689종), 일본어가 있는 64종을 골라 `text/envspec.py`에 지울 영역(주변 색으로 가로·세로 보간 또는 단색)과 한글 문구를 적었습니다. `text/envmap.json`은 각 번호가 들어 있는 파일·인덱스 목록입니다.
- 다시 그린 그림은 원래 형식으로 인코딩하고 밉맵도 새로 만듭니다. 한 줄 높이가 10px 이하인 글씨는 갈무리 7·9·11을 원래 픽셀 크기로 그립니다.

## 동영상 (XMV)

- 시작 경고 화면(`warning.xmv`)은 한 장의 경고 그림이 밝아졌다 어두워지는 2초짜리 영상입니다. 가장 밝은 프레임의 글자를 지우고 한글 경고문을 그린 뒤 각 프레임 밝기 비율로 다시 만들었습니다(`mvwarn.py`).

- 오프닝(`opening_bt.xmv`, 5.1ch판 `opening_bt51.xmv`)과 엔딩(`ED_02J.xmv`)에는 일본어 자막이 영상에 구워져 있고, 같은 장면의 자막 없는 판(`opening_b*.xmv`, `ED_02E.xmv`)이 함께 들어 있습니다.
- 두 영상의 자막 영역 차이로 자막 구간을 찾고(`mvseg.py`), 자막 없는 영상 프레임 위에 한글 자막을 그려 WMV2로 인코딩합니다(`mvsub.py`, PyAV).
- `xmvmux.py`가 원본 XMV의 패킷 구조와 오디오를 그대로 두고 영상 데이터만 바꿉니다. 패킷 크기 한도를 넘지 않도록 프레임마다 비트레이트를 맞추고, 정지 화면은 건너뛰기 프레임으로 줄였습니다.
